2. HTTP Status & Headers:

3. Directory Structure Inspection:
   Inspected the route files inside `app/`:
   $ ls -la disposable-404-test/app
   Found `layout.tsx` and `index.tsx`, but NO `page.tsx`.

4. Framework Architectural Rule Verification:
   Consulted Next.js App Router conventions:
   - In Next.js Pages Router (legacy), `pages/index.tsx` was the root page.
   - In Next.js App Router (`app/`), route endpoints MUST be named `page.tsx`
     (or `page.jsx`/`page.js`).
   - A file named `index.tsx` inside an `app/` directory is treated as an unrouted
     internal file, not a route leaf.

Actual Cause:
Because no `page.tsx` existed in the root of `app/`, the App Router router tree
contained no match for path `/`. Next.js automatically fell back to its internal
`/_not-found` boundary, compiled 670 modules for the error view, and returned
an HTTP 404 status.
