4. PLAIN WORDS EXPLANATION
--------------------------------------------------------------------------------
When AI coding agents are asked to build a scaffold, they frequently invoke
scaffolding CLIs (like `create-next-app <project-name>`) without realizing that the
user has already created and opened the target project folder. This creates an
unintended folder-in-a-folder (`my-project/my-project/package.json`).

When someone types `npm run dev` in the outer folder, npm cannot find `package.json`
and throws a fatal ENOENT error.

- Recovery 1 fixes the immediate blocker by `cd`-ing into the inner folder. The app
  runs, but the folder structure remains messy and violates repository conventions.
- Recovery 2 permanently fixes the problem at the architectural level: the agent
  scaffolds directly into the root folder (`./`). The application starts cleanly
  from the top level, allowing CI/CD, Docker, and developers to work seamlessly.
